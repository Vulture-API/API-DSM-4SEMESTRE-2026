# Backlog da Sprint 1

## Sprint 1

| ID | Prioridade | User Story | Planning Poker | Sprint | Critérios de Aceitação |
|---|---|---|---:|---:|---|
| **US01** | Alta | Como Administrador, quero cadastrar e gerenciar estações meteorológicas, para controlar as estações instaladas. | 8 | 1 | **CA1:** O sistema deve permitir cadastrar uma estação meteorológica.<br>**CA2:** Os campos Código, Nome e Localização devem ser obrigatórios.<br>**CA3:** O sistema não deve permitir códigos duplicados.<br>**CA4:** O sistema deve permitir editar os dados de uma estação cadastrada.<br>**CA5:** O sistema deve permitir ativar e desativar estações.<br>**CA6:** O sistema deve exibir mensagem de sucesso após o cadastro ou alteração. |
| **US02** | Alta | Como Administrador, quero cadastrar sensores e parâmetros, para permitir diferentes tipos de medições. | 8 | 1 | **CA1:** O sistema deve permitir cadastrar sensores vinculados a uma estação.<br>**CA2:** Os campos Nome, Tipo de Medição e Unidade de Medida devem ser obrigatórios.<br>**CA3:** O sistema deve permitir definir limites mínimos e máximos para cada sensor.<br>**CA4:** O sistema deve permitir editar sensores cadastrados.<br>**CA5:** O sistema não deve permitir cadastrar sensores sem associação a uma estação.<br>**CA6:** O sistema deve exibir mensagem de sucesso após o cadastro ou alteração. |
| **US03** | Alta | Como Administrador, quero cadastrar e gerenciar usuários, para incluí-los no Sistema. | 8 | 1 | **CA1:** O sistema deve permitir cadastrar usuários.<br>**CA2:** Os campos obrigatórios devem ser validados no cadastro.<br>**CA3:** O sistema não deve permitir usuários com dados identificadores duplicados.<br>**CA4:** O sistema deve permitir editar os dados de usuários cadastrados.<br>**CA5:** O sistema deve permitir ativar e desativar usuários.<br>**CA6:** O sistema deve exibir mensagem de sucesso após o cadastro ou alteração. |
| **US04** | Alta | Como Gerente Agrícola, quero visualizar o status das estações, para identificar problemas de comunicação. | 5 | 1 | **CA1:** O sistema deve exibir todas as estações cadastradas.<br>**CA2:** O sistema deve apresentar o status de cada estação (Online, Offline ou Com Alerta).<br>**CA3:** O sistema deve exibir a data e hora da última comunicação da estação.<br>**CA4:** O sistema deve atualizar automaticamente o status conforme o envio de dados.<br>**CA5:** O sistema deve permitir filtrar estações por status. |
| **US05** | Alta | Como Gerente Agrícola, quero cadastrar e configurar alertas meteorológicos, para ser avisado sobre condições críticas. | 5 | 1 | **CA1:** O sistema deve permitir cadastrar alertas meteorológicos.<br>**CA2:** O sistema deve permitir selecionar o parâmetro meteorológico que acionará o alerta.<br>**CA3:** O sistema deve permitir definir condições ou limites para acionamento do alerta.<br>**CA4:** O sistema deve permitir ativar e desativar alertas cadastrados.<br>**CA5:** O sistema deve notificar o Gerente Agrícola quando uma condição configurada for atingida. |
| **US06** | Alta | Como Cliente, quero contar com a disponibilidade e escalabilidade do sistema, para suportar o crescimento das estações e atender ao SLA definido. | 13 | 1 | **CA1:** O sistema deve permanecer disponível durante sua operação.<br>**CA2:** O sistema deve suportar o crescimento da quantidade de estações cadastradas.<br>**CA3:** O sistema deve suportar o crescimento da quantidade de dados recebidos.<br>**CA4:** O sistema deve permitir monitorar a disponibilidade do sistema.<br>**CA5:** O sistema deve atender aos níveis de disponibilidade definidos no SLA. |
