# Requisitos Não Funcionais (RNF)

Os requisitos não funcionais definem características de qualidade, desempenho, segurança, confiabilidade e operação esperadas para o AgroClima 360.

| ID | Categoria | Descrição |
|---|---|---|
| **RNF01** | Desempenho | Processar dados em até 3 segundos. |
| **RNF02** | Disponibilidade | Disponibilidade mínima de 99%. |
| **RNF03** | Escalabilidade | Suportar crescimento de estações sem degradação significativa. |
| **RNF04** | Segurança | Permitir acesso apenas a usuários e dispositivos autorizados. |
| **RNF05** | Integridade | Garantir integridade dos dados armazenados. |
| **RNF06** | Confiabilidade | Registrar falhas e exceções para auditoria. |
| **RNF07** | Usabilidade | Interfaces intuitivas e de fácil utilização. |
| **RNF08** | Compatibilidade | Compatível com Chrome, Edge e Firefox. |
| **RNF09** | Manutenibilidade | Seguir padrões de desenvolvimento e documentação. |
| **RNF10** | Backup | Realizar backups periódicos. |
| **RNF11** | Auditabilidade | Gerar registros para rastreamento das operações. |
| **RNF12** | Disponibilidade da API | API disponível 24x7. |
