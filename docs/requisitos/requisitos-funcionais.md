# Requisitos Funcionais (RF)

Os requisitos funcionais descrevem as funcionalidades e comportamentos que o sistema AgroClima 360 deve disponibilizar.

| ID | Nome | Descrição |
|---|---|---|
| **RF01** | Cadastro de Estações Meteorológicas | O sistema deve permitir o cadastro, edição, ativação e desativação de estações meteorológicas. |
| **RF02** | Gerenciamento de Sensores | O sistema deve permitir o cadastro e gerenciamento de sensores vinculados às estações meteorológicas. |
| **RF03** | Configuração de Parâmetros | O sistema deve permitir definir parâmetros de validação para cada sensor. |
| **RF04** | Recebimento de Dados via API | O sistema deve disponibilizar uma API para recebimento dos dados enviados pelas estações. |
| **RF05** | Validação de Dados | O sistema deve validar a existência da estação, do sensor e a consistência dos dados. |
| **RF06** | Armazenamento de Dados | O sistema deve armazenar os dados meteorológicos recebidos. |
| **RF07** | Monitoramento das Estações | O sistema deve monitorar o status operacional das estações. |
| **RF08** | Identificação de Falhas | O sistema deve identificar falhas de comunicação ou inconsistências. |
| **RF09** | Exibição de Alertas | O sistema deve exibir alertas para estações ou sensores com problemas. |
| **RF10** | Consulta de Ocorrências | O sistema deve permitir consultar falhas e inconsistências registradas. |
| **RF11** | Visualização de Status | O sistema deve apresentar os status Online, Offline e Com Alerta. |
| **RF12** | Registro de Logs | O sistema deve registrar logs das requisições e erros. |
